JATUH SUKA — WEBSITE SURAT

Buka index.html di browser.
Website memakai embed YouTube untuk "TULUS - Jatuh Suka (Official Lyric Video)".
Karena musiknya adalah karya berhak cipta, file MP3 lagu tidak disalin ke paket ini.

Catatan:
- Saat tombol "buka suratnya" ditekan, halaman mencoba memulai musik.
- Browser tertentu tetap dapat meminta interaksi tambahan sebelum audio terdengar.
- Dua foto di assets/ berasal dari artwork yang dibuat sebelumnya; kalau mau mengganti dengan foto asli, ganti foto_1.png dan foto_2.png dengan foto lu, pakai nama file yang sama.
